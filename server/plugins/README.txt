Положите сюда файлы плагинов (.phar) для GenisysPro / PocketMine API 3.0.1.

Проще всего: отправьте .phar файл боту в Telegram — он сам положит его сюда
и предложит перезапустить сервер. Список установленных плагинов: /plugins

Внимание: плагины для PocketMine-MP 4/5 с этим ядром не работают — нужны
плагины под API 3.x (времён MCPE 1.1.x).
